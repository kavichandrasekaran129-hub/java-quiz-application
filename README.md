# ☕ Java Quiz Application

A responsive quiz application built using **HTML, CSS, and JavaScript**. Users can answer multiple-choice Java questions and instantly view their final score.

## 🚀 Features

- Multiple-choice Java quiz
- Interactive user interface
- Automatic score calculation
- Responsive design
- Restart quiz option

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```text
java-quiz-application/
│── index.html
│── style.css
└── script.js
```

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Open `index.html` in your browser (or use Live Server).
4. Start answering the quiz!
